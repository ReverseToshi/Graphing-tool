# Graphing Tool

## Introduction
Graphing Tool is a lightweight application for creating, inspecting, and exporting 2D plots and charts. It supports plotting mathematical functions and tabular datasets, interactive zoom/pan, and export to common image formats. Designed for quick exploration and reproducible plotting workflows.

## Features
- Plot mathematical expressions (e.g., y = sin(x), y = x^2)
- Interactive zoom, pan, and point inspection
- Export plots to PNG, SVG, or PDF
